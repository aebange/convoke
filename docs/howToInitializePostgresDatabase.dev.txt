How to Initialize the Convoke Postgres Database
---------------------------=-----------------
NOTE:  The flyway scripts cannot create a database
       Someone *must* create an empty database first


Procedure
---------
 1. Create the convoke_db and convoke_user
    unix> psql -U postgres -h localhost

          create database convoke_db;
          create user convoke_user with password 'secret';
          grant all privileges on database convoke_db to convoke_user;
          alter database convoke_db     SET search_path=convoke_db;
          alter role     convoke_user   SET search_path=convoke_db;
          \q

 2. Create the convoke_db schema
    unix> psql -U convoke_user -d convoke_db -h localhost
    password:

      create schema convoke_db;
      \q
